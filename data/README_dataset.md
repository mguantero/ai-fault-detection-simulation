# Data Directory

This directory contains the datasets used for the transmission line fault detection project.

## Files

- `transmission_line_data.csv`: The main dataset containing the electromagnetic parameters and fault types
- `transmission_line_data.mat`: MATLAB binary version of the dataset

## Dataset Structure

The dataset contains the following columns:

1. **Real_Permittivity**: Real part of the complex permittivity
2. **Imag_Permittivity**: Imaginary part of the complex permittivity
3. **Conductivity**: Electrical conductivity in S/m
4. **Refl_Coef_Magnitude**: Magnitude of the reflection coefficient
5. **Refl_Coef_Phase**: Phase of the reflection coefficient in radians
6. **VSWR**: Voltage Standing Wave Ratio
7. **Position**: Position of the fault from the source (in meters)
8. **FaultType**: Type of fault (Normal, Open, Short, or Mismatch)

## Data Generation

This dataset was synthetically generated by simulating a coaxial transmission line with different fault conditions. The electromagnetic parameters were calculated based on the physical properties of each fault type.
